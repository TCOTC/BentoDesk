# Contributing to BentoDesk

## English

BentoDesk is a fork of [DeskBox](https://github.com/Tianyu199509/DeskBox). Feedback is welcome through [Issues](https://github.com/TCOTC/BentoDesk/issues) for bugs, feature ideas, and UX notes.

If you plan a substantial change, please open an Issue first so scope and direction can be discussed before any Pull Request.

## 中文

BentoDesk 基于 [DeskBox](https://github.com/Tianyu199509/DeskBox) fork。欢迎通过 [Issue](https://github.com/TCOTC/BentoDesk/issues) 反馈 Bug、功能想法或交互建议。

若改动较大，请先开 Issue 讨论范围与方向，再提交 Pull Request。
