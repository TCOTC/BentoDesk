# BentoDesk 1.1.1

## English

BentoDesk 1.1.1 is a small hotfix for shortcut dragging in managed widgets.

### Download

- [BentoDesk_Setup_1.1.1_x64.exe](https://github.com/TCOTC/BentoDesk/releases/download/v1.1.1/BentoDesk_Setup_1.1.1_x64.exe)

### Fixed

- Fixed internal dragging for shortcut files (`.lnk`) in managed widgets. BentoDesk now keeps its own path-based drag metadata even when Windows cannot convert a shortcut into a `StorageItem`.

## 中文

BentoDesk 1.1.1 是一个针对收纳盒子快捷方式拖拽的小修复版本。

### 下载

- [BentoDesk_Setup_1.1.1_x64.exe](https://github.com/TCOTC/BentoDesk/releases/download/v1.1.1/BentoDesk_Setup_1.1.1_x64.exe)

### 修复

- 修复收纳盒子内快捷方式（`.lnk`）无法长按拖动的问题。即使 Windows 无法把快捷方式转换为 `StorageItem`，BentoDesk 也会使用自身的路径数据继续完成盒子内拖拽。
