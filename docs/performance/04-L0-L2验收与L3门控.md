# L0–L2 验收与 L3 门控

**状态：** 已落地 L0 / L1 / L2 代码路径  
**用途：** 在 120Hz + 多格子场景验收后，决定是否启动 L3 混合合成层

---

## 已落地内容

| 层级 | 改动摘要 |
|------|----------|
| L0 | 折叠 / 拖边期间冻结 `UpdateInteractiveSurfaces`，结束后一次性刷新 |
| L1 折叠 | 恢复 HWND 插值动画（丝滑生长/收缩）；动画期间冻结 item-surface 全量刷新 |
| L1 拖边 | 恢复实时改窗跟手，PointerMoved 合并到下一帧 VSync；拖边期间冻结 surface 刷新 |
| L2 | `ItemsView_SizeChanged` 只刷新列表文本宽度；布局签名缓存；表面 Opacity 走 Composition |

---

## 验收场景（必须人工跑）

环境建议：120Hz（或更高）主屏，文件盒子 ≥ 40 个图标，同时开 4+ 个格子。

1. **胶囊展开 / 折叠**  
   - 观察动画是否稳定接近显示器刷新率  
   - 首帧不应再出现明显 Acrylic 附着尖峰（仍有 2 帧延迟）  
   - 锚点角应保持不动（Scale 绕 pivot）

2. **边缘拖拽缩放**  
   - 拖动过程中真实格子内容不应每帧重排  
   - 仅预览轮廓跟手；松手后内容一次落位  
   - 吸附高亮在 snap 状态不变时应无重建闪烁

3. **列表模式改宽**  
   - SizeChanged 不应再触发全量 item layout  
   - 仅文本 MaxWidth 跟随容器宽度

---

## L3 门控（通过才开混合合成层）

同时满足以下任一条件再启动 L3：

- 120Hz 下折叠动画仍稳定低于 90fps，或肉眼持续掉帧  
- 多格子（≥ 8）同时动画时 UI 线程帧预算仍经常 > 12ms  
- 预览轮廓窗在多 DPI / 混合刷新率下出现明显不同步，且 L1 无法修好  

若以上都不成立：**停留在 L0–L2**，不要上 L3。

---

## L3 候选方向（未实施）

静止态保留多 HWND；动画 / 拖边时切入专用合成层或交换链，结束后回落。详见方案地图 L3 章节。
