# BentoDesk 文件格子与桌面整理指南

文件格子是 BentoDesk 最核心的功能。收纳格子按归属整理仍留在桌面目录中的文件；映射格子仍是真实文件夹入口。

本指南会说明文件实际存在哪里、哪些操作会改变真实文件，以及如何用少量格子建立稳定的桌面分类。

> [图片占位：一个「未分类」格子和一个分类收纳格子并排。标题清楚显示「未分类」和「待处理」，格子内使用真实文件图标]

## 收纳格子

收纳格子适合整理桌面上的文件。

运行时，BentoDesk 会隐藏 Windows 原生桌面图标列表，并只用格子显示桌面文件：

- **未分类（默认格子）**：桌面上有、且尚未归属到任何分类收纳格的文件
- **分类收纳格子**：已归属到该格子的桌面文件

文件的物理路径仍在用户桌面目录中。拖入分类收纳格子只会改变「归属」，不会把文件搬进 `%UserProfile%\BentoDesk\...` 之类的私有目录。

非桌面来源（如下载文件夹）拖入时，会先按设置复制或移动到桌面，再纳入格子显示。

退出 BentoDesk（或进程异常退出）后，原生桌面图标会由主程序或 DesktopGuard 恢复显示。

典型用途

- 未分类：承接尚未整理的桌面散落文件
- 待处理、截图、安装包、当前项目素材等分类收纳格

右键格子标题中的「打开桌面文件夹」会打开用户桌面目录。

系统会始终保留一个「未分类」默认格子；删除后会自动重建。

## 映射文件夹

映射文件夹适合快速访问已经存在的目录。

它不会创建副本，也不会改变目录位置。格子中显示的文件与资源管理器中是同一批真实文件。你在格子内执行重命名、移动或删除时，真实目录会同步变化。

典型用途

- 当前项目目录
- 代码仓库
- 设计素材库
- 常用模板
- 下载目录
- OneDrive 中的工作目录

映射的价值是缩短访问路径，不是把目录变成只读预览。

## 如何选择

| 需求 | 使用方式 |
| --- | --- |
| 整理桌面散落文件，希望图标只出现在格子里 | 收纳格子（未分类 + 分类格） |
| 已有目录结构，不希望移动 | 映射文件夹 |
| 从下载等位置收到桌面并归入格子 | 收纳格子，并将拖入行为设为移动或复制 |
| 只想在桌面快速查看项目目录 | 映射文件夹 |
| 希望退出软件后桌面图标恢复系统原样 | 收纳格子（自动恢复原生图标） |

## 创建和命名

从托盘右键菜单创建分类收纳格子，或者使用「映射文件夹」选择已有目录。首次启动会自动提供「未分类」默认格。

分类格子名称应该表达用途，而不是文件类型。比起「PDF」「图片」「文档」，更推荐

- 待处理
- 本周项目
- 客户交付
- 参考素材
- 常用模板

用途型命名更接近日常动作。自动叠放可以继续在一个用途格子内部按文件类型整理。

双击标题可以重命名。映射格子的显示名称与真实路径概念不同，以界面实际提示为准。

## 拖入文件

对分类收纳格子：

- 已在桌面的文件：只改变归属，进入该格并从「未分类」消失。
- 不在桌面的文件：先按设置复制或移动到桌面，再纳入格子。

拖入「未分类」：会解除其它分类格对该文件的归属（若有），文件仍在桌面目录，并重新出现在未分类列表中。

可以在 `设置 > 文件格子 > 收纳与路径` 中调整「非桌面来源」的复制/移动默认值。映射文件夹的拖放遵循目标真实目录的 Windows 文件操作语义。

拖入时请观察鼠标和格子提示，确认当前是复制、移动还是不允许操作。

## 移回桌面 / 回到未分类

从分类收纳格子「移回桌面」只会移出归属；文件本来就在桌面，会重新出现在「未分类」默认格中（运行时仍隐藏系统桌面图标列表）。

## 拖出文件

从格子把文件拖到资源管理器、聊天窗口或其他支持 Windows 拖放的软件。

拖出不是「导出」。文件本来就是普通桌面文件。目标软件决定接收方式。

## 打开、选择和批量操作

- 双击文件，使用 Windows 默认应用打开。
- Ctrl 加点击，添加或取消单个选择。
- Shift 加点击，选择连续范围。
- 在空白处拖动，使用选择框选择多个项目。
- 右键选中项目，执行复制、剪切、重命名、删除或打开文件位置。

删除、移动和重命名会作用于真实文件。批量操作前应确认选择范围。

## 图标视图和列表视图

图标视图适合图片、设计素材和需要视觉识别的内容。

列表视图适合办公文档、安装包和需要查看名称、类型、大小、日期的内容。是否显示详细信息可以在文件显示设置中调整。

可以按名称、大小、类型或修改时间等方式排序。具体可用项取决于当前版本界面。

如果图片预览让格子显得太乱，可以开启「图片文件仅显示图标」。这不会修改图片，只改变展示方式。

## 自动叠放

当一个格子开始出现十几个甚至几十个项目时，可以开启自动叠放。

叠放按类型、日期或自定义扩展名规则整理视觉分组，不会移动真实文件。详细配置参考 [文件自动叠放与 QuickLook](06-file-stacks-and-quicklook.md)。

## 文件格子的胶囊状态

格子可以收成胶囊，占用更少桌面空间。展开后继续使用同一批真实文件。

## 推荐分类方法

不要按扩展名建很多格子。更稳的做法是：

1. 使用系统提供的「未分类」默认格承接新到桌面的内容
2. 一到两个「本周项目」类收纳格子
3. 少量映射格子指向真正长期使用的工作目录

这样桌面保持清爽，文件仍在用户桌面目录中，退出软件后系统桌面图标会恢复。
