# BentoDesk 展开折叠指南

展开折叠让盒子在不使用时进入折叠态。文件盒子会折叠内容区、只保留原来的标题栏；音乐盒子使用独立的紧凑栏。

> [图片占位：同一个桌面的展开状态和折叠状态对比。文件盒子折叠后仍是原标题栏，音乐盒子为紧凑栏。]

## 从哪里设置

进入 `设置 > 展开折叠`。

可以从盒子标题栏的折叠按钮切换状态。文件盒子标题栏右键菜单也提供展开方式入口。

## 三种展开方式

### 保持展开

盒子不自动进入折叠。适合需要长期操作的主要工作盒子，也可以作为单个盒子的例外设置。

### 点击展开

点击折叠后的展开按钮（原折叠按钮在折叠态会变为展开）返回展开状态。它最容易理解，也最不容易误触，推荐新用户默认使用。

### 悬停展开

鼠标停留在标题中间的可展开区域，达到设定延迟后自动展开。移出并满足折叠条件后自动返回折叠态。

标题区域被分为三部分

- 左侧图标区，用于识别和拖动，不触发自动展开。
- 中间标题空白区，用于悬停展开。
- 右侧操作区，根据当前盒子实际按钮自适应宽度，包含按钮和拖动手柄，不触发自动展开。

操作区平时保持克制，鼠标进入标题后再显示必要提示。这样用户能看懂哪里可以移动，哪里可以展开。

> [图片占位：折叠态标题栏命中区域示意。使用三种半透明颜色标出左侧图标区、中间展开区、右侧操作与拖动区]

## 悬停响应

悬停响应控制的是「停多久才展开」和「移出多久才折叠」，不等于动画速度。仅在全局展开方式为「悬停展开」时出现。

预设建议

| 预设 | 适合场景 |
| --- | --- |
| 灵敏 | 熟悉展开折叠交互，希望快速查看 |
| 平衡 | 日常使用，响应与防误触之间折中 |
| 防误触 | 经常经过折叠态盒子或需要拖动 |
| 自定义 | 分别调整展开和折叠延迟 |

如果经常划过就展开，改成防误触。如果鼠标停住却觉得等待太久，改成灵敏或减少自定义展开延迟。

## 折叠后显示什么

### 文件盒子

折叠后只保留原来的标题栏（图标、名称、操作按钮），内容区域隐藏。不使用独立紧凑栏。

### 音乐盒子

使用独立紧凑栏：封面、正在播放的标题、进度与媒体控件。

音乐标题过长时沿用音乐盒子的单向跑马灯逻辑，避免来回滚动造成疲劳。

## 折叠宽度与位置

每个盒子可以有自己的折叠宽度和折叠位置，与展开状态分别保存。

- 调整折叠态宽度时，可在盒子菜单中恢复自动宽度。
- 拖动折叠态改变位置时，BentoDesk 记录折叠位置，不修改展开状态尺寸。
- `设置 > 展开折叠 > 已单独设置的盒子` 可查看并清除这些覆盖。

独立宽度更灵活，也更需要理解锚点。调整右边框时左边应该保持不动，调整左边框时右边保持不动。折叠位置不会因为修改展开尺寸而被重新计算。

## 展开锚点

展开和折叠都以折叠态所在边角为锚点。

- 靠近屏幕左侧，优先向右展开。
- 靠近屏幕右侧，优先向左展开。
- 靠近顶部，优先向下展开。
- 靠近底部，优先向上展开。

当横向和纵向空间同时受限时，BentoDesk 会结合工作区选择可见区域更大的方向。方向可以变化，但折叠态自身的锚点不应漂移。

动态布局盒子在展开前会先锁定目标布局，音乐不会在动画途中于中间尺寸反复换视图。

## 动画

动画设置控制展开和收回的运动感觉。

| 模式 | 说明 |
| --- | --- |
| 快速 | 响应直接，适合高频操作 |
| 平衡 | 默认平衡状态 |
| 舒缓 | 时间更长，视觉更从容 |
| 关闭 | 立即切换状态 |
| 自定义 | 手动调整过渡时长 |

动画速度和悬停响应不要混淆。动画决定开始后运动多久，悬停响应决定何时开始。

如果使用减少动态效果的 Windows 辅助设置，BentoDesk 的实际动画表现可能随系统能力调整。

## 拖入时临时展开

把文件、图片、文字或附件拖到折叠态时，盒子会临时展开。

流程

1. 内容进入折叠态有效区域。
2. BentoDesk 展开真实盒子，让你确认目标。
3. 松开后执行添加。
4. 拖放结束，盒子恢复原折叠状态。

临时展开不会保存为用户主动展开，也不会修改折叠位置或展开尺寸。

如果只是想移动折叠态，请从图标区或不会触发展开的标题操作区开始拖动。

## 单盒设置

单个盒子可以覆盖全局的展开方式、宽度和位置。覆盖后，全局设置变化可能不会作用于它。

`设置 > 展开折叠 > 已单独设置的盒子` 会按盒子列出覆盖内容，而不是只显示数量。可以逐个恢复跟随全局。

当出现「其他盒子都生效，只有这个盒子不一样」时，先检查单盒覆盖。

## 推荐预设

### 稳定入门

- 点击展开
- 标准 / 平衡动画

### 快速浏览

- 悬停展开
- 平衡响应
- 平衡动画

### 极简桌面

- 点击展开
- 按需要为个别盒子设置更短的折叠宽度
