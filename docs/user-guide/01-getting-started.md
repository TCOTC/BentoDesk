# BentoDesk 安装与首次配置

本指南帮助新用户从下载安装到创建第一个盒子。完成后，你应该能够用 F7 显示或隐藏全部盒子，并理解收纳盒子和映射文件夹的区别。

> [图片占位：BentoDesk 首次启动后的完整桌面，至少展示一个文件盒子和一个音乐盒子]

## 系统要求

推荐环境

- Windows 11 64 位
- .NET 10 Desktop Runtime x64
- Windows App Runtime 2.2 x64
- 普通 Windows 用户权限

BentoDesk 围绕 WinUI 3 和 Windows 11 的窗口、材质、圆角、拖放、通知与媒体会话能力设计。Windows 10 不属于当前推荐环境，部分视觉和交互可能无法完整工作。

BentoDesk 不需要以管理员身份运行。不要在快捷方式兼容性设置中勾选「以管理员身份运行此程序」。资源管理器通常以普通权限运行，BentoDesk 如果被提升为管理员权限，Windows 可能阻止两者之间的文件拖放。

## 下载安装包

安装包可以从官网或 GitHub Release 获取。

- 官网：<https://github.com/TCOTC/BentoDesk>
- GitHub Release：<https://github.com/TCOTC/BentoDesk/releases>
- 文件名形如：`BentoDesk_Setup_<版本>_x64.exe`

从 GitHub 下载时，可以同时下载 `.sha256` 校验文件并核对哈希。

## 安装过程

安装器不会把 .NET 10 和 Windows App Runtime 2.2 的完整安装程序打进 BentoDesk 安装包。它会先检查目标电脑

- 依赖已经存在，直接跳过。
- 缺少依赖，联网下载对应运行时。
- BentoDesk 正在运行，先关闭进程，再替换文件。

这种方式可以控制安装包体积，也避免每次升级重复安装相同运行时。

> [图片占位：安装器依赖检查页面。分别标注「已安装，跳过」和「缺少，准备下载」两种状态]

## 首次启动引导

首次启动会依次帮助你完成外观、功能盒子、快捷键和开机启动等配置。收纳盒子整理的是仍留在用户桌面目录中的文件，不会再要求你选择单独的收纳根目录。

### 选择外观

第一次使用建议保留以下默认思路

- 主题跟随 Windows。
- 材质使用云母。
- 显示密度使用标准或舒适的默认状态。
- 边框和圆角先跟随默认值。

确认日常阅读和拖放都舒服以后，再进入外观设置调整透明度、材质浓度、边框颜色和密度。

### 启用功能盒子

音乐盒子可以单独开启。关闭后，创建入口会隐藏，但不会影响其他类型盒子。

音乐依赖当前播放器是否支持 Windows 系统媒体会话。

### 设置快捷键和开机启动

默认全局快捷键是 F7。

- 按一次，显示或唤起全部盒子。
- 再按一次，隐藏全部盒子。

如果 F7 与其他软件冲突，可以进入 `设置 > 快捷与交互 > 全局快捷键` 重新录制。

开机启动适合希望 BentoDesk 长期常驻托盘的用户。如果只是先体验，可以暂时关闭，确认工作流后再开启。

## 创建第一个盒子

右键系统托盘中的 BentoDesk 图标，选择创建盒子。

建议第一个分类盒子命名为「待处理」。它用于承接暂时不知道该归档到哪里，但不希望继续散落在桌面上的文件。系统还会保留一个「未分类」默认盒，显示尚未归属到任何分类盒的桌面文件。

把一张测试图片拖进去。文件仍留在用户桌面目录；盒子只记录归属。从下载等非桌面位置拖入时，会先按设置复制或移动到桌面，再纳入盒子显示。

接着使用「映射文件夹」选择一个常用目录。映射不会复制目录，它直接展示真实位置中的内容。

> [动图占位：托盘创建「待处理」盒子，拖入图片，再映射一个项目文件夹]

## 新用户推荐初始配置

| 项目 | 推荐值 | 原因 |
| --- | --- | --- |
| 全局快捷键 | F7 | 单键显示或隐藏全部盒子 |
| 非桌面文件拖入 | 复制 | 初次使用更不容易误移动来源文件 |
| 展开折叠 | 先保持展开 | 先熟悉完整盒子的操作 |
| 自动叠放 | 先关闭 | 文件较多后再开启更容易理解效果 |

## 覆盖升级

从旧版本升级时，可以直接运行新安装包覆盖安装。正常情况下会保留

- 盒子配置、位置和尺寸
- 桌面上的实际文件（收纳盒不另建私有目录）
- 外观、快捷键和其他设置
- 折叠与展开状态的保存数据

重要版本升级前，建议进入 `设置 > 诊断与维护 > 备份与恢复` 导出 ZIP 备份。覆盖安装不会替代数据备份。

## 卸载前检查

卸载前建议完成两件事

1. 用资源管理器打开用户桌面目录，确认重要文件可独立访问。
2. 导出一份 BentoDesk 数据备份。

收纳盒子中的文件本身就在桌面上，不会因为应用消失就变成不可读格式。卸载程序可能询问是否删除本地应用数据（设置与布局）。操作前应看清选项。
